# SEO Listing Hub

A professional browser-based e-commerce SEO toolkit for creating and optimizing marketplace product listings.

## Features

- SEO title generation with marketplace character limits
- SEO product description generation
- Five structured bullet points
- Search keyword formatting
- Keyword coverage analysis
- Existing listing SEO audit
- Missing keyword detection
- Repeated keyword detection
- One-click copy buttons
- Copy-all output
- Responsive desktop/mobile interface
- No Node.js, npm or API key required for the basic version

## Supported Marketplaces

- Amazon
- eBay
- Shopify
- TikTok Shop
- Temu
- Generic marketplace listings

## Marketplace Title Limits

| Marketplace | Limit |
|---|---:|
| Amazon | 200 characters |
| eBay | 80 characters |
| Shopify | 255 characters |
| TikTok Shop | 255 characters |
| Temu | 255 characters |
| Generic | 255 characters |
